<div class="pitch home-pitch">
    Persia DB is an embedded search database for Rust. Think "SQLite for search": it runs inside your
    process and keeps an index in one <code>.persia</code> file. Open the file, index documents, and get
    ranked results that, by default, never come back empty. A query that matches nothing is relaxed
    step by step, and the response says what changed.
</div>

<div class="pitch-planned">
    Planned: the same segment bytes in object storage (S3, GCS, or Azure Blob), served by a gRPC and
    HTTP server and by stateless query nodes on Kubernetes.
</div>

```toml title="Cargo.toml"
[dependencies]
persia = { git = "https://github.com/tomiok/persiaDB" } # not on crates.io yet
```

```rust title="src/main.rs"
use persia::{Db, SearchRequest};

fn main() -> persia::Result<()> {
    let db = Db::open("app.persia")?; // one file, created if missing
    let notes = db.create_collection_json(
        r#"{"name": "notes", "fields": {"body": {"type": "text"}}}"#,
    )?;
    notes.put_json(r#"{"id": "n1", "body": "hello, world"}"#)?;
    notes.commit()?;

    // A typo still finds n1, and the response names the step that relaxed it.
    let page = notes.search(&SearchRequest::new("helo"))?;
    assert_eq!(page.hits[0].document.id(), "n1");
    println!("{:?}", page.relaxation.level); // Fuzzy

    db.close()
}
```

## Why this exists

| Property | What it means | Status |
|---|---|---|
| Zero friction | `Db::open("app.persia")` just works. No daemon and no config file for the embedded library. | Works: `persia::Db`, `OpenOptions`, and `Collection`. |
| Own engine | Index format, analysis, BM25F scoring, and query execution are written in this repository. | %%PILLAR_ENGINE%% |
| Never zero results | A query that matches nothing is relaxed step by step, and the response says what changed. | %%RELAXATION_CELL%% [Query relaxation and zero results](/guide/typo-tolerant-search/). |
| Cloud-native | Immutable segments. The same bytes locally and in object storage. Stateless query nodes. | %%PILLAR_CLOUD%% |
| Correctness, then speed | Checksums, crash-safe commits, and fuzzed parsers come before performance claims. | %%PILLAR_CORRECTNESS%% |

The design contract is [SPEC.md](https://github.com/tomiok/persiaDB/blob/main/SPEC.md) (draft v0.1).
When this site and the SPEC disagree, the SPEC wins.
