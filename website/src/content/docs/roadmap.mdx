Work is a tree of milestones, `M0` through `M15`. Every leaf is one issue and one pull request.
This table is the **2026-10-11** snapshot from
[PROGRESS.md](https://github.com/tomiok/persiaDB/blob/main/PROGRESS.md): **69 of 406 leaves, 17%**.
That file is regenerated from checkboxes in
[ROADMAP.md](https://github.com/tomiok/persiaDB/blob/main/ROADMAP.md) and is the live status.
No leaf is marked in progress. M1 is the active milestone (43 of 53 leaves done).

A milestone is **done** when every leaf is done, **in progress** when some are done,
**ready** when its dependencies are done and its own leaves have not started, and **blocked**
while a dependency is unfinished.

| Milestone | Delivers | Depends on | Snapshot |
|---|---|---|---|
| **M0** Bootstrap | Workspace, CI, tooling, docs scaffolding | — | Done, 26/26 |
| **M1** Format primitives | Encodings, codecs, header, frames | M0 | In progress, 43/53 |
| **M2** Storage | `Storage`, memory, local file, container | M1 | Blocked, 0/25 |
| **M3** Schema | Collections, documents, manifests | M1 | Blocked, 0/15 |
| **M4** Text analysis | Tokenizers, stemmers, analyzers | M0 | Ready, 0/22 |
| **M5** Segments | Segment writer and reader | M1, M3, M4 | Blocked, 0/36 |
| **M6** Durability | WAL, commit, merge, recovery | M2, M5 | Blocked, 0/29 |

Block framing (1.5) and the container header and superblock (1.6) are done.
Frame encode, decode, and scan (1.7.1–1.7.4) are done.
The next format work is the streaming frame encoder (1.7.5), then mmap (1.8).
Text analysis (M4) may proceed alongside that.
What each milestone contains, in prose, is the [milestones page](/guide/roadmap/).
