Persia is a library you open on a file, plus a server that embeds the same engine.
The engine is synchronous. It talks to disks and object storage only through a `Storage` trait
that does not exist yet. Async belongs in the cloud backends and in the server.

## Storage and segments

A segment is one byte string: sections, then a footer. Locally it is a frame payload. Remotely it is
one object. The bytes match. Codecs on a block are `None` and `Zstd`. The container and the backends
are still ahead of the code.
